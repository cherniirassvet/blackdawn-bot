# Бот «Чёрный Рассвет» — установка с нуля

Всё делается в браузере, отдельная программа для SSH не нужна: у Oracle
есть встроенный терминал прямо на сайте.

---

## Часть 1. Заводим сервер в Oracle Cloud

**1.1** Открой `oracle.com/cloud/free` и нажми **Start for free**.

**1.2** Заполни регистрацию. Что важно:

- **Home Region** выбирается один раз и навсегда. Бери **Germany Central
  (Frankfurt)** или **Sweden Central (Stockholm)** — до Telegram и до
  DonationAlerts оттуда близко.
- Попросят банковскую карту. Деньги не спишут, это проверка личности:
  повиснет и вернётся примерно доллар. **Российские карты Oracle часто не
  принимает** — если откажет, напиши мне, пойдём другим путём.

**1.3** После регистрации в консоли Oracle нажми гамбургер слева вверху →
**Compute** → **Instances** → **Create instance**.

**1.4** Настройки инстанса:

- **Name**: `blackdawn-bot`
- **Image**: нажми **Change image** → **Canonical Ubuntu** → версия **24.04**
- **Shape**: нажми **Change shape** →
  - вкладка **Ampere** → `VM.Standard.A1.Flex`, поставь 1 ядро и 6 ГБ памяти.
  - Если пишет, что мощностей нет (у Oracle это обычное дело), переключись на
    вкладку **Specialty and previous generation** и возьми
    **`VM.Standard.E2.1.Micro`**. Он всегда свободен, и боту его хватает с запасом.
  - Под обоими вариантами должна гореть надпись **Always Free eligible**. Если
    не горит — ты выбрал платный, вернись и поменяй.
- **Networking**: галка **Assign a public IPv4 address** должна стоять.
- **Add SSH keys**: выбери **Generate a key pair for me** и нажми
  **Save private key**. Файл `ssh-key-....key` скачается — он понадобится,
  не теряй.

**1.5** Жми **Create**. Через минуту-две статус станет зелёным **RUNNING**.
Запиши **Public IP address** с этой страницы.

---

## Часть 2. Заходим на сервер

**2.1** В правом верхнем углу консоли Oracle нажми иконку терминала
(**Developer tools → Cloud Shell**). Внизу откроется чёрное окно — это
терминал прямо в браузере.

**2.2** В Cloud Shell нажми на три точки → **Upload** и залей тот самый файл
ключа `ssh-key-....key`.

**2.3** Выполни по очереди (вместо `ВАШ_IP` подставь адрес из шага 1.5):

```
chmod 600 ssh-key-*.key
ssh -i ssh-key-*.key ubuntu@ВАШ_IP
```

Спросит `Are you sure you want to continue connecting` — отвечай `yes`.
Приглашение сменится на `ubuntu@blackdawn-bot:~$` — ты на своём сервере.

## Часть 3. Ставим бота

**3.1** Готовим окружение:

```
sudo apt update && sudo apt install -y python3-venv python3-pip unzip
mkdir -p ~/bot && cd ~/bot
python3 -m venv venv
```

**3.2** Положи сюда файлы бота: `bot.py`, `rcon.py`, `shop.py`,
`setup_da.py`, `requirements.txt`, `config.example.ini`,
`blackdawn-bot.service`.

Проще всего — через Cloud Shell: в нём нажми **Upload**, залей архив с
файлами, а потом из Cloud Shell перекинь его на сервер:

```
scp -i ssh-key-*.key bot.zip ubuntu@ВАШ_IP:~/bot/
```

и уже на сервере:

```
cd ~/bot && unzip -o bot.zip
```

**3.3** Ставим библиотеки:

```
cd ~/bot
./venv/bin/pip install -r requirements.txt
```

**3.4** Делаем свой файл настроек:

```
cp config.example.ini config.ini
nano config.ini
```

Впиши: токен бота, свой Telegram ID, rcon-пароль сервера, client_id и
client_secret из DonationAlerts. Сохранить в nano: `Ctrl+O`, `Enter`,
выйти: `Ctrl+X`.

**3.5** Привязываем DonationAlerts — один раз:

```
./venv/bin/python3 setup_da.py
```

Скрипт даст ссылку. Открой её в любом браузере, разреши доступ. Тебя
перекинет на страницу, которая не откроется — это нормально. Скопируй
адрес из адресной строки целиком и вставь обратно в терминал.

**3.6** Пробный запуск:

```
./venv/bin/python3 bot.py
```

В Telegram должно прийти «🟢 Бот запущен». Напиши боту `/online` — должен
ответить картой и числом игроков. Останови проверку: `Ctrl+C`.

**3.7** Ставим на автозапуск, чтобы бот пережил перезагрузку:

```
sudo cp ~/bot/blackdawn-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now blackdawn-bot
systemctl status blackdawn-bot
```

Должно быть `active (running)`.

---

## Что дальше

- Посмотреть, что бот делает: `journalctl -u blackdawn-bot -f` (выйти `Ctrl+C`).
- Перезапустить после правки настроек: `sudo systemctl restart blackdawn-bot`.
- Поменять цены: правь `config.ini`, потом перезапусти.

## Что должно быть написано на странице доната

Чтобы автовыдача срабатывала, донатер обязан указать в сообщении, что берёт
и свой SteamID. Например:

```
VIP STEAM_0:1:12345678
```

или

```
админка навсегда STEAM_0:1:12345678
```

Если человек ошибётся — бот ничего не выдаст молча, а пришлёт тебе донат в
Telegram с пометкой, что не так, и ты выдашь руками командой
`/vip STEAM_0:1:12345678 30`.
