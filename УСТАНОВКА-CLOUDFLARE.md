# Бот на Cloudflare Workers — установка

Бесплатно, карта не нужна, работает круглосуточно. Всё делается в браузере,
можно с телефона, но с компьютера удобнее.

---

## Часть 1. Аккаунт и воркер

**1.1** Открой `dash.cloudflare.com/sign-up`, заведи аккаунт на почту.
Карту не просят. Подтверди почту.

**1.2** В панели слева → **Compute (Workers)** → **Workers & Pages** →
**Create** → **Start with Hello World!** → **Deploy**.

Имя дай `blackdawn-bot`. После деплоя у тебя появится адрес вида
`https://blackdawn-bot.ТВОЙ-ПОДДОМЕН.workers.dev` — **запиши его**, он нужен дальше.

**1.3** Открой воркер → **Edit code**. Сотри всё, что там есть, и вставь
содержимое файла `worker.js`. Нажми **Deploy**.

---

## Часть 2. Хранилище

**2.1** Слева → **Storage & Databases** → **KV** → **Create Instance**.
Имя: `blackdawn`. Создать.

**2.2** Вернись в воркер → **Settings** → **Bindings** → **Add** →
**KV Namespace**:

- Variable name: `STATE`
- KV namespace: `blackdawn`

Сохранить.

---

**3.2 Секреты** (тип Secret — значение скрывается после сохранения):

| --- | --- |

После добавления нажми **Deploy**, иначе переменные не подхватятся.

---

## Часть 4. Ключ панели хостинга

Бот отдаёт команды серверу через панель, поэтому ему нужен ключ.

**4.1** Открой панель → правый верхний угол → **Account** → **API Credentials**.

**4.2** Создай ключ. Описание любое, например `blackdawn-bot`.
Поле с IP оставь пустым — Cloudflare ходит с разных адресов.

**4.3** Ключ покажут **один раз**. Скопируй и вставь в секрет `PANEL_KEY`.

---

## Часть 5. Крон

Воркер → **Settings** → **Trigger Events** → **Add** → **Cron Trigger**.
Расписание: `* * * * *` — раз в минуту. Сохранить.

---

## Часть 6. Подключаем Telegram

Открой в браузере одну ссылку, подставив свои значения:

```
https://api.telegram.org/botТОКЕН/setWebhook?url=https://АДРЕС-ВОРКЕРА/tg&secret_token=ТВОЙ_TG_WEBHOOK_SECRET
```

В ответ должно прийти `{"ok":true,...,"description":"Webhook was set"}`.

Проверь: напиши боту `/start`. Должен ответить сразу.

---

## Часть 7. Привязываем DonationAlerts

**7.1** В приложении на `donationalerts.com/application/clients` поменяй
Redirect URI на:

```
https://АДРЕС-ВОРКЕРА/da/callback
```

**7.2** Открой в браузере:

```
https://АДРЕС-ВОРКЕРА/da/login?key=ТВОЙ_SETUP_KEY
```

Тебя перекинет на DonationAlerts, нажми «Разрешить». Вернёт на страницу
с надписью «Готово. DonationAlerts привязан».

---

## Проверка

1. Напиши боту `/online` — покажет карту и список игроков.
2. `/top` — пятнадцать первых.
3. `/vip STEAM_0:1:1 1` — команда уйдёт на сервер, бот скажет, появилась ли
   запись в файле.
4. Сделай себе донат на минимальную сумму с текстом `вип STEAM_0:1:твой_id`.
   В течение минуты придёт уведомление о выдаче.

## Если что-то не так

- Логи: воркер → **Logs** → **Begin log stream**.
- Донаты не читаются — бот сам напишет тебе в Telegram, но не чаще раза в час.
- Поменял цены в переменных — не забудь **Deploy**.

## Чем этот вариант отличается от версии на Python

- Онлайн и топ бот берёт из файлов сайта, которые обновляет робот GitHub
  раз в 15 минут. То есть `/online` показывает сводку до четверти часа
  давности, и бот честно пишет, когда она снята.
- Команды серверу уходят через панель, а не по RCON: ответ сервера панель не
  возвращает, поэтому выдачу VIP бот проверяет отдельно — читает файл
  `zm_vip.ini` и смотрит, появился ли там SteamID.
- Донаты забираются опросом раз в минуту, а не мгновенным вебсокетом.
